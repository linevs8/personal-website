# Daniel Lim – Personal Portfolio Website

**Live Website**: [Click here to view the portfolio](https://linevs8.github.io/personal-portfolio/)

This is a personal portfolio website built to showcase my skills, background, and academic/computer science projects.

---

## Structure

- `index.html` – Home page (intro + photo)
- `about.html` – Background, education, interests
- `skills.html` – Categorized technical and non-technical skills
- `contact.html` – Contact form + social links
- `projects.html` – List of all projects with links to:
  - `project-hanoi.html`
  - `project-matrix.html`
  - `project-tcp.html`
  - `project-collab.html`

## Technologies
- HTML5
- CSS3 (with media queries and transitions)
- JavaScript
